Conectar la oficina

La oficina lee el estado del repo privado grosoar/groso-oficina. La clave queda guardada solo en este navegador y solo se manda a GitHub.

  1. Con la cuenta grosoar, abrí GitHub → Fine-grained token nuevo.
  2. Nombre: uno por aparato (ej. oficina-celular) · Vencimiento: 1 año · Repository access: Only select repositories → groso-oficina.
  3. Permissions: Contents y Actions en Read and write.
